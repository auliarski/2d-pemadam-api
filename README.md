# Pemadam Api - Game 2D dengan p5.js

Tugas Proyek Grafika Komputer.

## Struktur
- `index.html`        : halaman utama
- `sketch.js`         : kode game (setup, draw, logika, tampilan)
- `style.css`         : tampilan halaman
- `libraries/p5.min.js` : pustaka p5.js v1.9.4 (lokal, bisa offline)

## Kontrol
- Gerak: tombol panah / A D, atau geser mouse
- Semprot air: SPASI atau klik mouse
- Main lagi: tekan R atau klik saat permainan selesai
- Layar penuh browser: tekan F (keluar dengan Esc)

## Aturan
- Padamkan 5 api dalam 60 detik.
- Tangkap botol air untuk mengisi ulang tangki.
- Hindari bara api (3 nyawa).

## Pengaturan cepat (bagian atas sketch.js)
`JUMLAH_API`, `WAKTU_AWAL`, `NYAWA_AWAL`
